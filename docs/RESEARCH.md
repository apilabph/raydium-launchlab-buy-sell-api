# Protocol and product evidence

The owner's portfolio selected this venue using 7-day and 30-day volume, not subscriber counts. These are independent integrations. The practical value offered here is an inspectable build response with slot, minimum output, exact fee simulation, rent disclosure and migration rejection. We have not established that these checks are unique to this service.

Official sources checked October 13, 2026:

- https://github.com/MeteoraAg/dynamic-bonding-curve
- https://github.com/MeteoraAg/dynamic-bonding-curve-sdk
- https://github.com/raydium-io/raydium-sdk-V2
- https://github.com/raydium-io/raydium-cpi/tree/master/programs/launch-cpi
- Jupiter mainnet-published IDL and https://dev.jup.ag/docs/swap/build-swap-transaction

The SDK versions and dependency graph are pinned in package-lock.json. Generated offsets are committed and reproducible. No keys or private RPC URLs are part of this repository.
